# huynle.com

Source for [huynle.com](https://huynle.com): a static [Astro](https://astro.build) site with a short **Now**
snapshot, **Projects**, and **Writing**.

- Posts are written in this repo (`src/content/posts/`) and published by merging a PR to `main`.
- `src/content/projects/` and `src/content/now.md` are generated from Brain by a reviewed sync PR.
- Merging to `main` builds an immutable container image (`ghcr.io/huynle/huynle.com`) that Flux rolls out.

## Develop

Node 22.22+ and npm 11.

```sh
npm ci
npm run dev           # http://localhost:4321 (drafts visible)
npm run check         # astro check (types + content schemas)
npm test              # vitest
npm run build         # static site in dist/ (drafts excluded)
npm run verify:dist   # fail on draft slugs, private IPs, *.ts.net, emails, token-like strings in dist/
npm run check:links   # offline internal link check over dist/
BRAIN_URL=https://brain.huynle.com BRAIN_TOKEN=... npm run brain:export   # regenerate projects/now from Brain
```

Container (nginx-unprivileged on :8080, `/healthz`, custom 404, `/index.xml` → `/rss.xml`):

```sh
docker build -t huynle-site . && docker run --rm -p 8080:8080 huynle-site
```

## Content

| Collection | Location | Source |
|---|---|---|
| `posts` | `src/content/posts/*.md(x)` | written here; `draft: true` keeps a post out of production |
| `projects` | `src/content/projects/*.md` | generated from Brain (`public,site-project`); `brainId` is never rendered |
| `now` | `src/content/now.md` | generated from Brain (`public,site-now`) |

The two `sample-*` projects and the Now text are placeholders; the first Brain sync replaces them.

## Publishing from Brain

`src/content/projects/`, `src/content/now.md` and `src/assets/brain/` are generated by `scripts/brain-export.ts`. Do
not edit them by hand; the next sync overwrites them.

1. **Write a public-facing entry** in Brain (any project). Use one short entry per project, e.g. a `walkthrough`
   titled `Project: <name>`. Never tag internal plans or decisions; link them to the public entry instead.
2. **Tag it** `public` + `site-project` for a project card, or `public` + `site-now` for the Now snapshot (if several
   Now entries exist, the most recently modified wins; with none, `now.md` is left alone). Both tags are required.
3. **Shape the body:**
   - An optional leading `# Title` line is dropped.
   - The first paragraph becomes the card summary (inline markdown stripped).
   - A `## Links` section becomes the card links. Only `http(s)` items in this form are kept:

     ```md
     ## Links

     - [Source](https://github.com/huynle/example)
     - [Write-up](https://huynle.com/posts/example/)
     ```

   - Everything else is the card body. Images are copied only when the body references a Brain attachment, as
     `![alt](attachment:<attachment-id>)` or a `…/api/v1/attachments/<id>/content?project_id=<project>` URL; they
     are saved to `src/assets/brain/<id>.<ext>`.
4. **Status:** `active`/`in_progress` → active, `completed`/`validated` → shipped, `blocked`/`draft`/`pending` →
   paused. `archived`/`cancelled`/`superseded` entries are not exported.
5. **Title and file name:** a leading `Project:` is stripped; the file is `<slug-of-title>.md` (a colliding slug gets
   a `-<id>` suffix). Renaming the entry renames the file.

**Removal:** remove the `public` tag (or archive the entry). The next sync deletes its card and any images only it
used.

**Safety lint (fail closed):** before writing anything the export rejects entries containing private IPv4
(10/8, 172.16/12, 192.168/16, 100.64/10), `*.ts.net`, `.local`/`.lan`/`.internal`/`.corp` hostnames, email addresses,
or token/key-like strings. The job then fails with the entry id and rule name (never the matched value) and no PR is
opened. Fix the entry in Brain and re-run.

**Running the sync:** `brain-sync.yml` runs nightly (09:00 UTC) and on demand:

```sh
gh workflow run brain-sync.yml -R huynle/huynle.com
```

It commits changes to the `brain-sync` branch and opens or updates a single PR, **Brain sync: projects & now**. No
diff means no PR; an open sync PR that no longer differs from `main` is closed. Review and merge it like any other PR.
Pushes made with `GITHUB_TOKEN` don't trigger `ci.yml`, so the sync job runs tests, check, build, `verify:dist` and
the link check itself, then dispatches `ci.yml` on `brain-sync` so the PR shows the normal checks.

Auth: repo secrets `BRAIN_URL` and `BRAIN_TOKEN` (the Brain named token `huynle-site-export`, scope `read:*`). The
token can read all of Brain, so it is stored only in this repo and used only on the self-hosted runner.

## Workflows

- `ci.yml` (PRs and non-main pushes, self-hosted `amos` runner): check, test, build, `verify:dist`, link check, and a
  `docker build` with a container smoke test.
- `release.yml` (push to `main`, manual): `huynle/.github` `container-release.yml@v1` publishes
  `ghcr.io/huynle/huynle.com` with immutable `git-<UTC>-<sha>` and `sha-<sha>` tags.
- `brain-sync.yml` (nightly, manual): Brain export → `brain-sync` PR (see above).
